# meng-skills

中文论文与专业文本写作全流程技能包：**写前有清单、写中有规范、写后有自查、交付前有程序验证**。面向 CSSCI 实证论文（经济/金融/会计/管理），整合去 AI 味与降 AIGC 检测。

v0.40.0 基于 89 篇中文顶刊全文（经济研究/管理世界/金融研究/会计研究/中国工业经济/世界经济/南开管理评论/管理科学学报/经济学（季刊））程序化校准，并经过三轮独立 AI 审查（K3，39 条建议闭环）。

## 适用场景

| 路由 | 场景 | 示例 |
|------|------|------|
| 实证论文 | 摘要、引言、文献综述、理论分析、研究设计、回归结果、机制、异质性、稳健性、结论 | 经济学、金融学、会计学、管理学实证研究 |
| 课题/项目申请 | 申报书、社科基金、自然基金、研究基础、技术路线、创新点 | 各类科研基金申报 |
| 公文/纪要/报告 | 会议纪要、座谈纪要、调研报告、工作汇报、政策建议 | 行政与政策文档 |
| 专业评论/阐释 | 读书笔记、学术评论、概念阐释、专业分析 | 专业知识输出 |

**不适用：** 英文写作、日常聊天、代码注释、数据表头、引号内原话（政策文件原文豁免）。

## 核心能力

- **写前清单（§1.1）**：A 类必删词（18 个比喻/口语词，严于顶刊）+ B 类密度红线（顶刊常规词，超密度才改）——经 89 篇顶刊验证，红线内是顶刊常态表达
- **期刊人称光谱**：8 刊"我们/本文"比值 0.00-1.12（中国工业经济纯"本文"→ 经济学（季刊）"我们"为主），按目标期刊切换
- **分节写作规范（§9）**：基准回归、表格格式、平行趋势（含多期 DID：Goodman-Bacon 分解/CSDID/dCDH 权重诊断/安慰剂三件套）、稳健性、机制（方法选择论证段）、异质性、引言、摘要、制度背景与理论、结论、PSM、变量定义与描述性统计——每节顶刊范式 + 模板句
- **篇幅基准（§9.14）**：89 篇程序化统计——各章节中位字数、典型区间、正文段数、每段字数（正文段主流 100-450 字）
- **顶刊句式库**（references/top-journal-phrases.md）：89 篇金句按十章分类，含来源标注
- **自动化验证（§11）**：内置 Python 脚本（红线必须清零 + 提示级供人工过目），支持 `venue='季刊'` / `genre='专业评论'` 例外通道
- **深度模式（§10）**：降 AIGC 检测率五步闭环（定位扫描 → 诊断分类 → 差异化改写 → 五维自评 → 二次复查）
- **投稿返修（§15）**：投稿前检查清单 + 审稿意见逐条回应规范

## 安装

### Hermes Agent

```bash
# 将技能目录复制到 Hermes 技能目录
cp -r meng-skills ~/.hermes/skills/writing/
# 或使用 Hermes 技能管理命令（hermes skills install ...）
```

Agent 自动读取 `SKILL.md`，检测到中文专业写作任务时加载。

### 其他 Agent（Claude Code / Cursor / Codex / Kimi Code）

```bash
# 复制到项目的 .claude/skills/ 或 .cursor/ 目录
cp SKILL.md .claude/skills/meng-skills.md
cp -r references .claude/skills/meng-skills-references/
```

## 使用方法

### 标准模式（默认）

直接提交中文专业文本，技能自动：
1. 冻结事实（数据、引用、人名、政策编号不改）
2. 判断文体并路由（§2）
3. 清除 AI 痕迹（§3）
4. 按对应文体规则润色（§8）
5. 运行自动化验证（§11），输出红线报告 + 提示级清单

### 深度模式（降 AIGC 检测率）

明确要求"降 AIGC"、"去 AI 味"、"过知网检测"时启用：定位扫描 → 诊断分类 → 差异化改写 → 五维自评 → 二次复查，等使用者确认问题清单后再改写。

### 自动化验证脚本

```python
# 从 SKILL.md §11 提取 verify_text 后调用
verify_text(全文)                          # 常规验证
verify_text(全文, venue='季刊')            # 投稿经济学（季刊）：豁免"我们"密度红线
verify_text(全文, genre='专业评论')        # 专业评论：豁免"说白了"（§8.6）
```

违规项必须清零才能交付；提示级输出（问句数、加粗数、段末套句）列给使用者人工过目。
